## Tentang PERKOMINA

PERKOMINA adalah perhimpunan para komisaris independen di industri perasuransian Indonesia. Proyek ini dibuat untuk mendukung kebutuhan anggota terkait CV dan profil profesional.

## Status proyek

Repositori ini adalah rumah resmi proyek Perkomina CV: tempat penyimpanan kode, dokumentasi, dan catatan rilis.

## Struktur repositori

```
Perkomina-CV/
├── README.md     ← penjelasan proyek (file ini)
├── LICENSE       ← lisensi MIT
└── .gitignore    ← daftar file yang tidak ikut disimpan ke Git
```

## Privasi data

CV berisi data pribadi. Jangan pernah menyimpan data pribadi anggota (nomor KTP/NIK, nomor telepon, alamat rumah, dan sejenisnya), kata sandi, atau kunci API langsung di repositori ini. Simpan rahasia di file `.env` — file ini otomatis tidak ikut tersimpan ke Git.
